# Catalog Video (PixVerse) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user turn one of their completed catalogue images into a short video by picking an admin-curated "sample video" (each with its own PixVerse prompt), billed in credits, processed asynchronously by the existing dispatcher.

**Architecture:** Admin curates `sample_videos` rows (preview clip + poster thumbnail + PixVerse prompt) through a new admin CRUD screen, mirroring the existing `model_backgrounds` pattern. Users get a new "Catalog Video" nav item → history page → a 3-step picker (pick a completed catalogue image → pick a sample video → confirm). Submitting creates a `jobs` row exactly like `createSimpleTryonJob` does today (no face/background/pose, `jobInputs.params = { kind: 'video', sourceJobId, ... }`), which is enqueued to the existing Redis stream. The dispatcher's `processJob()` gets one new branch, `processVideoJob()`, that skips ComfyUI/worker selection entirely and instead calls PixVerse's image-to-video API directly, polls for completion, downloads the result, and uploads it to R2 — reusing `transitionJob()` so the existing SSE/status infrastructure (`useJobStream` on the frontend) works unchanged.

**Tech Stack:** Fastify 5 + zod (apps/api), Drizzle ORM (packages/db), Redis Streams (dispatcher), Next.js 15 (apps/catalogues-web), Vite+React (apps/admin-web). No new dependencies — PixVerse is called via plain `fetch()`, matching the existing Razorpay/ComfyUI client style.

## Global Constraints

- pnpm workspaces only — never introduce npm/yarn lockfiles.
- ESM only, Node 20+, TypeScript 5.6.
- No `console.log` in committed code — use `@tryme/logger` child loggers.
- `packages/types` is the single source of truth for request/response Zod shapes — define new shapes there, not inline in route files.
- Credit deduct + job insert must be one Postgres transaction; refund on terminal failure is also transactional (existing `atomicDeduct`/`refund` helpers — do not reimplement).
- `@tryme/db` exports `* as schema` from `packages/db/src/index.ts` — do not add a duplicate `schema` re-export.
- No testcontainers. Integration tests reuse the docker-compose Postgres/Redis/MinIO already running on localhost (`pnpm docker:up` must be running before `pnpm test`).
- Only commit when a full task's tests pass — do not commit partial/broken work.
- PixVerse's exact API contract (endpoint paths, field names) is not yet known — this plan writes a complete, runnable integration built around a generic "create task → poll for status → download result URL" async video API shape (this is how essentially every third-party video-gen API works, including PixVerse per its public docs). **Before running Task 8**, fetch PixVerse's real API reference (e.g. their developer docs site) and adjust only the endpoint path / request-body field names / response field names inside `apps/dispatcher/src/pixverse/client.ts` to match — the surrounding structure (function names, signatures, callers, tests) does not change.

```ts
  // ── Sample Videos (PixVerse catalog-video templates) ──────────────────────

  app.get('/admin/assets/sample-videos', { preHandler: RW }, async () => {
    const rows = await app.db
      .select()
      .from(schema.sampleVideos)
      .where(isNull(schema.sampleVideos.deletedAt))
      .orderBy(schema.sampleVideos.sortOrder);
    return { items: rows };
  });

  app.post(
    '/admin/assets/sample-videos/presign',
    { preHandler: RW, schema: { body: PresignSampleVideoBody } },
    async (req) => {
      const { videoContentType, thumbnailContentType } = req.body as {
        videoContentType: string;
        thumbnailContentType: string;
      };
      const newId = randomUUID();
      const videoR2Key = keys.sampleVideo(newId);
      const thumbnailR2Key = keys.sampleVideoThumb(newId);
      const [video, thumbnail] = await Promise.all([
        app.storage.presignPut(videoR2Key, videoContentType, 50_000_000, 300),
        app.storage.presignPut(thumbnailR2Key, thumbnailContentType, 5_000_000, 300),
      ]);
      return { videoUploadUrl: video.url, videoR2Key, thumbnailUploadUrl: thumbnail.url, thumbnailR2Key };
    },
  );

  app.post(
    '/admin/assets/sample-videos',
    { preHandler: RW, schema: { body: ConfirmSampleVideoBody } },
    async (req) => {
      const body = req.body as {
        title: string;
        videoR2Key: string;
        thumbnailR2Key: string;
        prompt: string;
        sortOrder: number;
      };
      const [row] = await app.db
        .insert(schema.sampleVideos)
        .values({
          title: body.title,
          videoR2Key: body.videoR2Key,
          thumbnailR2Key: body.thumbnailR2Key,
          prompt: body.prompt,
          sortOrder: body.sortOrder,
        })
        .returning();
      return row;
    },
  );

  app.patch(
    '/admin/assets/sample-videos/:id',
    { preHandler: RW, schema: { params: uuidParam, body: PatchSampleVideoBody } },
    async (req) => {
      const { id } = req.params as { id: string };
      const body = req.body as Record<string, unknown>;
      const [updated] = await app.db
        .update(schema.sampleVideos)
        .set({ ...(body as object), updatedAt: new Date() })
        .where(eq(schema.sampleVideos.id, id))
        .returning({ id: schema.sampleVideos.id });
      if (!updated) throw new AppError('NOT_FOUND', 404, 'sample video not found');
      return { ok: true };
    },
  );

  app.delete(
    '/admin/assets/sample-videos/:id',
    { preHandler: D, schema: { params: uuidParam } },
    async (req) => {
      const { id } = req.params as { id: string };
      const [row] = await app.db
        .select()
        .from(schema.sampleVideos)
        .where(eq(schema.sampleVideos.id, id));
      if (!row) throw new AppError('NOT_FOUND', 404, 'sample video not found');
      await app.db
        .update(schema.sampleVideos)
        .set({ deletedAt: new Date() })
        .where(eq(schema.sampleVideos.id, id));
      return { ok: true };
    },
  );
```

```tsx
  thumbnailR2Key: string;
  prompt: string;
  isActive: boolean;
  sortOrder: number;
}

function uploadErrorMessage(status: number): string {
  return `Upload failed (status ${status})`;
}

async function putFile(url: string, file: Blob, contentType: string): Promise<void> {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open('PUT', url);
    xhr.setRequestHeader('Content-Type', contentType);
    xhr.onload = () =>
      xhr.status >= 200 && xhr.status < 300
        ? resolve()
        : reject(new Error(uploadErrorMessage(xhr.status)));
    xhr.onerror = () => reject(new Error('Network error during upload'));
    xhr.send(file);
  });
}
```

```ts
  app: FastifyInstance,
  userId: string,
  body: z.infer<typeof CreateCatalogVideoJobRequest>,
) {
  const { sourceJobId, sampleVideoId } = body;
  const COST = await getPixverseCreditCost(app);

  const [source] = await app.db
    .select({ jobUserId: schema.jobs.userId, jobStatus: schema.jobs.status })
    .from(schema.jobs)
    .where(eq(schema.jobs.id, sourceJobId));
  if (!source) throw new AppError('NOT_FOUND', 404, 'source image not found');
  if (source.jobUserId !== userId) {
    throw new AppError('FORBIDDEN', 403, 'source image not owned by caller');
  }
  if (source.jobStatus !== 'COMPLETED') {
    throw new AppError('VALIDATION', 400, 'source image is not a completed job');
  }

  const [sample] = await app.db
    .select({
      isActive: schema.sampleVideos.isActive,
      deletedAt: schema.sampleVideos.deletedAt,
      prompt: schema.sampleVideos.prompt,
    })
    .from(schema.sampleVideos)
    .where(eq(schema.sampleVideos.id, sampleVideoId));
  if (!sample || sample.deletedAt) throw new AppError('NOT_FOUND', 404, 'sample video not found');
  if (!sample.isActive) throw new AppError('VALIDATION', 400, 'sample video is not active');

  const [[user], [planRow]] = await Promise.all([
    app.db.select().from(schema.users).where(eq(schema.users.id, userId)),
    app.db
      .select({ queueStream: schema.creditPlans.queueStream })
      .from(schema.users)
      .innerJoin(schema.creditPlans, eq(schema.users.tier, schema.creditPlans.slug))
      .where(eq(schema.users.id, userId)),
  ]);
  if (!user || user.isBanned) throw new AppError('FORBIDDEN', 403, 'banned');

  const queueStream: string = planRow?.queueStream ?? 'normal';
  const priority = queueStream === 'priority';
  const sourceImageKey = keys.output(sourceJobId);

  const [job] = await app.db.transaction(async (tx) => {
    const [newJob] = await tx
      .insert(schema.jobs)
      .values({
        userId,
        status: 'QUEUED',
        priority,
        queueStream,
        watermark: false,
        creditsCharged: COST,
        source: 'catalog_video',
      })

    await atomicDeduct(tx as unknown as DB, userId, COST, newJob.id);
    await tx.insert(schema.jobInputs).values({

      params: { kind: 'video', sourceJobId, sourceImageKey, sampleVideoId, prompt: sample.prompt },
    });
    return [newJob];
  });

  const stream = `jobs:${queueStream}`;
  try {
    await app.redis.xadd(stream, 'MAXLEN', '~', 10000, '*', 'jobId', job.id, 'userId', userId);
```

```ts
export async function createVideoTask(
  baseUrl: string,
  apiKey: string,
  imageUrl: string,
  prompt: string,
  log?: { info: (obj: unknown, msg: string) => void; error: (obj: unknown, msg: string) => void },
): Promise<PixverseTaskResult> {
  const url = `${baseUrl.replace(/\/$/, '')}/openapi/v2/video/img/generate`;
  log?.info({ url }, 'POST → PixVerse create video task');
  const res = await fetch(url, {
    method: 'POST',

    signal: AbortSignal.timeout(30_000),
  });
  if (!res.ok) {
    const text = await res.text().catch(() => '');
    log?.error({ url, status: res.status, body: text }, 'PixVerse create task failed');
    throw new Error(`PixVerse create task failed: ${res.status} ${text}`);
  }
  const json = (await res.json()) as { task_id: string };
  return { taskId: json.task_id };
}

export async function getVideoTaskStatus(
  baseUrl: string,
  apiKey: string,
  taskId: string,
): Promise<PixverseStatusResult> {
  const url = `${baseUrl.replace(/\/$/, '')}/openapi/v2/video/result/${taskId}`;
  const res = await fetch(url, {
    headers: apiHeaders(apiKey),
    signal: AbortSignal.timeout(15_000),
  });
  if (!res.ok) throw new Error(`PixVerse status check failed: ${res.status}`);
  const json = (await res.json()) as {
    status: string;
    video_url?: string;
    error_message?: string;
  };
  if (json.status === 'SUCCESS') return { status: 'SUCCESS', videoUrl: json.video_url };
  if (json.status === 'FAILED') return { status: 'FAILED', error: json.error_message };
  return { status: 'GENERATING' };
}

export async function pollVideoTask(
  baseUrl: string,
  apiKey: string,
  taskId: string,
  intervalMs: number,
  timeoutMs: number,
): Promise<string> {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    const result = await getVideoTaskStatus(baseUrl, apiKey, taskId);
    if (result.status === 'SUCCESS' && result.videoUrl) return result.videoUrl;
    if (result.status === 'FAILED') throw new Error(result.error ?? 'PixVerse generation failed');
    await new Promise((resolve) => setTimeout(resolve, intervalMs));
  }
  throw new Error('PixVerse generation timed out');
}
```

```ts
    await transitionJob(db, pub, jobId, userId, 'GENERATING', {}, jobLog);
    const { taskId } = await createVideoTask(
      env.PIXVERSE_API_BASE_URL,
      env.PIXVERSE_API_KEY ?? '',
      imageUrl,
      prompt,
      jobLog,
    );
    await db.insert(schema.jobEvents).values({
      jobId,
      eventType: 'PIXVERSE_DISPATCH',
      payload: { taskId },
    });

    const videoUrl = await pollVideoTask(
      env.PIXVERSE_API_BASE_URL,
      env.PIXVERSE_API_KEY ?? '',
      taskId,
      env.PIXVERSE_POLL_INTERVAL_MS,
      env.PIXVERSE_POLL_TIMEOUT_MS,
    );

    await transitionJob(db, pub, jobId, userId, 'UPLOADING', {}, jobLog);
    const videoRes = await fetch(videoUrl, { signal: AbortSignal.timeout(120_000) });
    if (!videoRes.ok) throw new Error(`failed to download PixVerse video: ${videoRes.status}`);
    const videoBytes = new Uint8Array(await videoRes.arrayBuffer());

    const resultKey = keys.videoOutput(jobId);
    await s3.send(
      new PutObjectCommand({
        Bucket: r2Bucket,
        Key: resultKey,
        Body: videoBytes,
        ContentType: 'video/mp4',
      }),
    );

    await transitionJob(db, pub, jobId, userId, 'COMPLETED', { resultKey }, jobLog);
    await redis.xack(stream, 'dispatcher-cg', messageId);
    recordJobOutcome('success', startedAt);
  } catch (err) {
    const errMsg = err instanceof Error ? err.message : String(err);
    await handleFailure(cfg, jobId, userId, stream, messageId, jobLog, startedAt, errMsg);
  }
}
```

```tsx
'use client';

import { useState } from 'react';
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { api } from '@/lib/api';
import { C } from '@/components/tokens';

interface CatalogueImageOption {
  jobId: string;
  catalogueId: string;
  thumbUrl: string | null;
}

interface SampleVideoOption {
  id: string;
  title: string;
  thumbnailUrl: string;
  previewVideoUrl: string;
}

export function CatalogVideoWizard({ onClose, onCreated }: { onClose: () => void; onCreated: () => void }) {
  const qc = useQueryClient();
  const [step, setStep] = useState<1 | 2 | 3>(1);
  const [sourceJobId, setSourceJobId] = useState<string | null>(null);
  const [sampleVideoId, setSampleVideoId] = useState<string | null>(null);
  const [submitting, setSubmitting] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const { data: catalogues } = useQuery({
    queryKey: ['catalogues'],
    queryFn: () => api.get<Array<{ catalogueId: string; coverThumbUrl: string | null; jobs: Array<{ id: string; status: string }> }>>('/v1/catalogues'),
  });

  const { data: sampleVideos } = useQuery({
    queryKey: ['sample-videos'],
    queryFn: () => api.get<{ items: SampleVideoOption[] }>('/v1/models/sample-videos'),
    enabled: step >= 2,
  });

  const imageOptions: CatalogueImageOption[] = (catalogues ?? []).flatMap((cat) =>
    cat.jobs
      .filter((j) => j.status === 'COMPLETED')
      .map((j) => ({ jobId: j.id, catalogueId: cat.catalogueId, thumbUrl: cat.coverThumbUrl })),
  );

  const handleSubmit = async () => {
    if (!sourceJobId || !sampleVideoId) return;
    setSubmitting(true);
    setError(null);
    try {
      await api.post('/v1/jobs/catalog-video', { sourceJobId, sampleVideoId });
      qc.invalidateQueries({ queryKey: ['catalog-videos'] });
      onCreated();
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Failed to start video generation');
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <div style={{ position: 'fixed', inset: 0, background: 'rgba(0,0,0,0.5)', zIndex: 50, display: 'flex', alignItems: 'center', justifyContent: 'center' }}>
      <div style={{ background: C.card, borderRadius: 16, padding: 24, width: 640, maxHeight: '80vh', overflowY: 'auto' }}>
        <div style={{ display: 'flex', justifyContent: 'space-between', marginBottom: 16 }}>
          <h2 style={{ color: C.text }}>New Catalog Video</h2>
          <button onClick={onClose}>×</button>
        </div>

        {step === 1 && (
          <>
            <p style={{ color: C.mid }}>Step 1 of 3 — pick an image</p>
            <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(120px, 1fr))', gap: 12 }}>
              {imageOptions.map((opt) => (
                <button
                  key={opt.jobId}
                  onClick={() => setSourceJobId(opt.jobId)}
                  style={{
                    border: sourceJobId === opt.jobId ? `2px solid ${C.pink}` : `1px solid ${C.border}`,
                    borderRadius: 8,
                    padding: 0,
                    overflow: 'hidden',
                    aspectRatio: '3/4',
                  }}
                >
                  {opt.thumbUrl && <img src={opt.thumbUrl} alt="" style={{ width: '100%', height: '100%', objectFit: 'cover' }} />}
                </button>
              ))}
            </div>
            <div style={{ marginTop: 16, textAlign: 'right' }}>
              <button disabled={!sourceJobId} onClick={() => setStep(2)}>
                Next
              </button>
            </div>
          </>
        )}

        {step === 2 && (
          <>
            <p style={{ color: C.mid }}>Step 2 of 3 — pick a sample video</p>
            <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(160px, 1fr))', gap: 12 }}>

                </button>
              ))}
            </div>
            <div style={{ marginTop: 16, display: 'flex', justifyContent: 'space-between' }}>

              <button disabled={!sampleVideoId} onClick={() => setStep(3)}>
                Next
              </button>
            </div>
          </>
        )}

        {step === 3 && (
          <>
            <p style={{ color: C.mid }}>Step 3 of 3 — confirm</p>
            <p style={{ color: C.text }}>Generate this catalog video?</p>
            {error && <p style={{ color: 'crimson' }}>{error}</p>}
            <div style={{ marginTop: 16, display: 'flex', justifyContent: 'space-between' }}>

              <button disabled={submitting} onClick={handleSubmit}>

              </button>
            </div>
          </>

    </div>
  );
}
```

```tsx
'use client';

import { useCallback, useState } from 'react';
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { api } from '@/lib/api';
import { C } from '@/components/tokens';
import { useJobStream } from '@/hooks/use-job-stream';
import { CatalogVideoWizard } from './CatalogVideoWizard';

interface CatalogVideoItem {
  id: string;
  status: string;
  createdAt: string;
  videoUrl: string | null;
  thumbnailUrl: string | null;
}

export default function CatalogVideoPage() {
  const qc = useQueryClient();
  const [wizardOpen, setWizardOpen] = useState(false);

  const { data: items, isLoading } = useQuery<CatalogVideoItem[]>({
    queryKey: ['catalog-videos'],
    queryFn: () => api.get('/v1/catalog-videos'),
    refetchInterval: 5 * 60 * 1000,
  });

  useJobStream(
    useCallback(
      (evt) => {
        qc.setQueryData<CatalogVideoItem[]>(['catalog-videos'], (old) => {
          if (!old) return old;
          return old.map((item) => (item.id === evt.jobId ? { ...item, status: evt.status } : item));
        });
        if (evt.status === 'COMPLETED') {
          qc.invalidateQueries({ queryKey: ['catalog-videos'] });
        }
      },
      [qc],
    ),
  );

  return (
    <div style={{ padding: 24 }}>
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 24 }}>
        <h1 style={{ color: C.text }}>Catalog Video</h1>
        <button onClick={() => setWizardOpen(true)}>New Catalog Video</button>
      </div>

      {isLoading ? (
        <p style={{ color: C.mid }}>Loading…</p>
      ) : !items || items.length === 0 ? (
        <p style={{ color: C.mid }}>No catalog videos yet — create your first one.</p>
      ) : (
        <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(240px, 1fr))', gap: 16 }}>
          {items.map((item) => (
            <div
              key={item.id}
              style={{ border: `1px solid ${C.border}`, borderRadius: 14, overflow: 'hidden', background: C.card }}
            >
              <div style={{ aspectRatio: '3/4', background: C.lighter }}>
                {item.status === 'COMPLETED' && item.videoUrl ? (
                  <video src={item.videoUrl} poster={item.thumbnailUrl ?? undefined} controls style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
                ) : item.thumbnailUrl ? (
                  <img src={item.thumbnailUrl} alt="" style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
                ) : (
                  <div style={{ display: 'flex', alignItems: 'center', justifyContent: 'center', height: '100%', color: C.mid }}>
                    {item.status}
                  </div>
                )}
              </div>
              <div style={{ padding: 8, fontSize: 12, color: C.mid }}>{item.status}</div>
            </div>
          ))}
        </div>
      )}

      {wizardOpen && (
        <CatalogVideoWizard onClose={() => setWizardOpen(false)} onCreated={() => setWizardOpen(false)} />
      )}
    </div>
  );
}
```
